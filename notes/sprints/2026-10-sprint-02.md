## Framing (locked 2026-10-03)

- **The software factory is the product.** Smart Writer V2 is the workload that exercises and perfects it. Both must be awesome; neither is the sole goal.
- Practices under development: spec-driven development, test-driven development, multi-agent offload (orchestrator → workers/reviewers via git bus) so the human and orchestrator stay at product/process altitude.
- **SNR = intent fidelity over autonomy time.** The longer agents run unattended, the more they drift from desired outcome. Countermeasures: (1) upfront capture of visible **and** invisible intent; (2) codify intent into rules, tests, evals, and hooks so drift is caught mechanically.

## Execution posture (SNR)

- ≤ **3** concurrent workers (locked 001 F2; review bandwidth is the constraint, not compute). Wave 2 has four lanes, so Ship (independent, smallest) queues behind the first lane to finish.
- Packets small: ≲ half-day worker time, ≲ ~400 diff lines, one owned-path set — cap autonomy length rather than hope it holds.
- Each packet lists intent ids + checks; workers cannot report done until checks pass (stop hook).
- **Verify, don't trust:** acceptance from CI per intent id; reviewer is a different model family, sees diff + check results + intent ids, not the worker narrative.
- Orchestrator reads structured handoffs + CI, not worker transcripts.
- One order → one branch → one PR; no bookkeeping commits.
- Bootstrap caveat: Wave 1 is built before its gates exist — hold to manual equivalents, then run new gates retroactively.
