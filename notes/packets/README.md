# Work packets (lab overlay)

Optional long-run wrappers around Spec Kit tasks. Default breakdown is still `tasks.md` via `/speckit-tasks`.

```text
notes/packets/
  _TEMPLATE.md
  <id>.md
```

Use when an agent should run 30–180 minutes with hard owned paths + DoD.
