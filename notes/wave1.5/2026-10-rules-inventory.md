## 2. Inventory

How to read the rows. **Type** is one of four: **hard** (a machine blocks the action whatever the agent intends), **warned** (a machine detects and reports but does not block), **prose** (written in a rule, process or skill file; holds only if the AI follows it), **habit** (practice in operating notes or handovers, not stated as lab policy). **Recommendation** is keep, rewrite (how), drop, or merge (into another row).

### Bypass legend (used in the hard and warned rows)

- **Ruleset bypasses.** The `main-protection` ruleset (id 24554609) is active on the default branch with no bypass actors (`current_user_can_bypass: never`). It still does not bind: (a) the governor as repository admin, who can edit or disable the ruleset itself; (b) review: the pull-request rule requires **0 approvals** and no code-owner review, so whoever opens a PR can merge it once the checks are green; (c) freshness: `strict_required_status_checks_policy` is false, so a PR that was green against an older `main` can merge. Classic branch protection could not be read (HTTP 403): **unknown**, not counted as hard.
- **Gate bypasses.** All factory gates feed one required status, `factory/gates`, which is green only when every CI gate passed or was overridden. (a) **Override file:** a failing gate turns green when the order has `bus/orders/<order-id>/override-NN.yaml` naming the gate, the PR and a reason; for `drift` gates the actor may be `orchestrator` or `governor`, for `governor-only` gates it must be `governor`. Because `factory.toml` sets `identity.mode = "recorded"`, the actor field is **not verified**: any agent can write `actor: governor`. (b) Order-scoped gates pass on PRs that link no order (but R24 refuses those, except bus-only PRs). (c) The ruleset bypasses above. The gates run `main`'s code on the PR head as data, so a PR cannot weaken the gate that judges it.
- **Hook bypasses.** Cursor hooks bind only Cursor agents (chat agents and, per reliability trial 4, the Cursor command-line agent); not people, not GitHub Actions. The wrapper `.cursor/hooks/factory-hook.sh` fails open (allows) when neither the project's venv, `uv` nor `nix` answers, and any crash fails open. `shell-guard` parses the command text, so a command inside a script file, a Python subprocess, or nested more than five shells deep is not seen. Only `shell-guard` can deny; the other three hooks only add messages.
