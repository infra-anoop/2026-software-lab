# Outside sources for the Wave 1.5 approach, copied into git

Reviewers and workers read these copies instead of fetching the web: a background agent's web request can wait on an approval prompt nobody sees (two reviews stalled that way on 2026-10-19; confirmed by trial on 2026-10-20). Reads outside the working copy were not the cause; they stay off limits as hygiene only (reliability report, section 4.2).
