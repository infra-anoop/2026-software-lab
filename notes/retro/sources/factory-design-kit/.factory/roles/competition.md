# Role: competition reviewer

**Focus:** whether the product is differentiated from what already exists.

**Check:**
- The spec names the closest existing tools or products.
- It states what this one does that they do not, and why a user would switch.
- Features that merely copy an existing free tool are questioned.

**Do not flag:** implementation details.

**Calibration:**
- blocker: the core feature is a free built-in of a tool the user already has.
- major: no comparison to the obvious alternative.
- minor: a differentiator stated but not reflected in any requirement.
