# Contract — bus messages

Source of truth: Pydantic models in `scripts/factory/src/factory/bus/`. Generated JSON Schema: `scripts/factory/schemas/<kind>.schema.json` (regenerated by `factory check schema --write`; CI fails if stale). Field tables: [`../data-model.md`](../data-model.md).

## Layout

```text
bus/
├── orders/<order-id>/
│   ├── order.yaml            # on main (issued)
│   ├── amendment-NN.yaml     # on main
│   ├── handoff.yaml          # on wo/<order-id> branch → merges with work
│   ├── run.yaml              # on branch
│   ├── verdict-NN.yaml       # on branch
│   └── override-NN.yaml      # on branch
├── decisions/<decision-id>/{request,lock}.yaml
├── corrections/<correction-id>.yaml
└── postmortems/<sprint>.yaml
```

## Invariants (each is a check)

| Invariant | Check id |
|-----------|----------|
| Every file validates against its kind's schema | `bus.schema` |
| No existing bus file is modified or deleted in a PR (append-only) | `bus.immutable` |
| No message contains `status`/`state`/`done`/`progress` keys | `bus.no-handwritten-status` |
| A PR from `wo/<id>` adds files only under `bus/orders/<id>/` (plus its owned paths) | `diff-within-owned-paths` |
| Decision request text has no ids/jargon (`\b[TFRPD]\d+\b`, `FR-\d+`, `SC-\d+`, `US\d+`, `§`) | `decision-request-no-ids` |
| Verdict inputs are git paths only; reviewer family ≠ author family | `verdict.reviewer-family-differs`, `verdict.inputs-isolated` |
| Override reason non-empty; governor-only gate ⇒ governor actor (verified under D4-A/B) | `message.override` |
